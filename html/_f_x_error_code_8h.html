Detailed Description

Error code definitions and function return status types for the FX system.

This header defines standardized error identifiers used across FX SDK components. It includes two primary categories:

  • System-level and servo-related error codes (FXErrorCode)
  • Function return status values (FXFuncReturn)

These enumerations are referenced by both low-level (L0) and high-level (L1) APIs to indicate operation results, fault conditions, and communication failures.

Detailed Description

Common definitions, enumerations, data structures, and utilities for the FX robot system SDK.

This header serves as the foundational include for both low-level (L0) and high-level (L1) APIs. It defines core types, versioning macros, object identifiers, state machines, feedback structures, and control parameters shared across the FX software stack.
